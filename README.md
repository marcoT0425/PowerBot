# PowerBot
PowerBot is a tool to calculate the powers of your customised number with the depth you've customised with the TurboWarp function "BigInt".

# Utility
1. For the code, type like `3 count 5`, which means 3 from the power of zero to five. The structure is like `[Base]` + `["Count"]` + `[Max Power]`
2. Be aware that your device ie like Mac or Windows will have been crashed if the file size is too big. I have set some questions to answer before you test it to ensure safety so as not to crash. If you haven't experienced that when opening this project, you must answer the questions following in the screen from the dialogues.
3. The program will automatically calculate the time remaining to finish the test and the byte size using MB as the unit, like this.
